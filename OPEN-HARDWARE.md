# Dolivo Rev A open hardware release

Rev A is the planned first certification candidate. The release owner can use this checklist to track the exact sources a carrier designer or independent builder would need.

1. **Verify the Dolivo interface.** Trial-place and route the independent 64-contact LGA, check pad 1 against the carrier top view, and confirm manufacturability before freezing the land pattern. See the [draft coordinates](LGA-Pinout.md).
2. **Finish the editable hardware.** Publish the verified contact map, native KiCad module and carrier footprints, assembly orientation, routed PCB and custom libraries. Document the tool version, pin voltages and alternate functions. Distinguish the default R7 build from the R8 build in the BOM and placement data.
3. **Prepare a reproducible release.** From a fresh checkout, open the project, resolve libraries, run ERC and DRC, and regenerate the BOM, Gerbers, drill and placement files. Include assembly and bring-up instructions. Record power, BOOTSEL, USB, flash, PSRAM and LGA test results against the tested board revision. These tests are Dolivo engineering milestones.
4. **Publish a versioned source release.** Put the hardware revision and source URL on the board or accompanying documentation. Tag the exact commit used for fabrication and publish an accessible release page containing editable sources, BOM, licensing notices, build files and known limitations. Include source or sufficient open interface documentation for software needed to operate the design. Record third-party dependencies and any modifications. [OSHWA documentation checklist](https://certification.oshwa.org/process/documentation.html)
5. **Apply for that revision.** The owner should review the application and affirmations and submit the public release URL. Once OSHWA grants certification, add the assigned UID and certification mark in accordance with its instructions and link them to the certified revision. Register a later revision when the earlier documentation no longer describes it. [Application](https://certification.oshwa.org/apply.html) · [Certification FAQ](https://certification.oshwa.org/basics/faq.html)
